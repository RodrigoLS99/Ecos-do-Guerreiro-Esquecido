# Documentação do Projeto

Este diretório centraliza todos os documentos de design, especificações técnicas, narrativa e atividades desenvolvidas no projeto Ecos do Guerreiro Esquecido.

---

## Estrutura da Documentação

### 1. Documentação do Jogo (`docs/jogo/`)
Reúne os documentos fundamentais de concepção, narrativa, design de sistemas e implementação técnica:
- `definicao_do_projeto.pdf`: Documento formal de definição de escopo, pilares fundamentais e premissa do jogo.
- `one_page_gdd_ecos_do_guerreiro_esquecido.pdf`: Sumário executivo em página única sintetizando os pilares centrais de game design.
- `sgdd_ecos_do_guerreiro_esquecido.pdf`: Documento de System Game Design com o detalhamento das regras lógicas, mecânicas de física, combate e progressão.
- `historia_e_universo.md`: Crônica aprofundada do reino, ambientação dos cinco andares, caracterização das entidades e análise dos múltiplos finais.
- `documentacao_tecnica.md`: Especificação técnica completa sobre arquitetura de software, nós e cenas, gerenciadores globais, sintetizador de áudio procedural e esteira de CI/CD.

Para consultar o índice específico do jogo, acesse [docs/jogo/README.md](jogo/README.md).

---

### 2. Atividades e Estudos de Projetos de Jogos (`docs/atividades/`)
Reúne as análises estruturais, reconstruções de documentos e estudos comparativos realizados nas etapas de planejamento:
- `analise_estrutural_de_jogos.pdf`: Análise formal sobre a estrutura e os sistemas centrais de jogos de referência do gênero.
- `reconstrucao_de_um_game_design_document.pdf`: Estudo de engenharia reversa e reconstrução de um Game Design Document.
- `analise_comparativa_entre_game_design_documents.pdf`: Estudo comparativo entre diferentes metodologias de documentação em projetos de jogos.

Para consultar o índice específico das atividades, acesse [docs/atividades/README.md](atividades/README.md).
